# Task Manager

A full-stack task management application built with React, Redux, Node.js, Express.js, and PostgreSQL.

## Features

- User registration and authentication
- Secure login and logout
- Profile and password management
- Create, edit, delete, and sort tasks
- Responsive user interface
- REST API integration

 ## Tech Stack

### Frontend

- React
- Redux
- JavaScript
- CSS
- Vite

### Backend

- Node.js
- Express.js

### Database

 - PostgreSQL

### Tools

- Git
- GitHub
- Postman

## Project Structure

task-tracker/

## Installation

Clone the repository:


git clone https://github.com/karandasha-dev/task-manager.git


Install dependencies:


cd client
npm install

cd ../server
npm install

### Start the backend:

npm start

### Start the frontend:

npm run dev
